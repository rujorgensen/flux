What is Flux?

Real-time messaging infrastructure — without the headaches.

Flux is a lightweight, real-time pub/sub messaging framework for TypeScript. It lets your services, agents, and clients talk to each other instantly — across networks, behind firewalls, and without you having to wire up WebSockets yourself.

Think of it like a switchboard for your application: agents dial in, channels open up, and messages flow freely — all in real time.

Core Concepts

Flux is built around three moving parts that work together:

FluxMesh

The server. It runs the mesh network that all agents and authorities connect to. Think of it as the hub in a hub-and-spoke architecture.

@persistica/flux-mesh

FluxAgent

The client. Agents connect to a mesh network, join channels, and send or receive messages. Each agent needs a network code to gain entry.

@persistica/flux-agent

FluxAuthority

The gatekeeper. Authorities decide who gets into your network and which channels they're allowed to subscribe to.

@persistica/flux-authority

How it fits together

Here's the big picture. Your FluxMesh server is running somewhere in the cloud (or locally). A FluxAuthority registers itself with the mesh and acts as a bouncer — it validates agents before they can join. FluxAgents connect to the mesh using a network code, get validated, then join channels to exchange messages in real time.

FluxAgent ──connect(code)──▶ FluxMesh ──validate?──▶ FluxAuthority
◀──authorized──────────────────────────
FluxAgent ──joinChannel('chat')──▶ FluxMesh

Why Flux?

  • Zero boilerplate — no WebSocket plumbing, no broker config, no custom handshake logic. Just install and go.
  • Auth baked in — the Authority pattern means you write your auth logic (JWT, API key, whatever), and Flux handles the rest.
  • TypeScript first — full type safety across your network boundary. If it compiles, it works.
  • Channel-based pub/sub — agents can publish to named channels and subscribe to them independently. No topic trees to manage.
  • Portal included — this very dashboard lets you create networks, generate access tokens, and monitor connected agents and authorities in real time.
