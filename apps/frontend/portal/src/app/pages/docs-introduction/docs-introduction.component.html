What is Flux?

Real-time messaging infrastructure — without the headaches.

Flux is a lightweight, real-time pub/sub messaging framework for TypeScript. It lets your services, agents, and clients talk to each other instantly — across networks, behind firewalls, without wiring up WebSockets yourself.

Core Concepts

FluxMesh

The server. Runs the mesh network that all agents and authorities connect to.

@persistica/flux-mesh

FluxAgent

The client. Connects to a mesh network, joins channels, and sends or receives messages.

@persistica/flux-agent

FluxAuthority

The gatekeeper. Decides who gets into your network and which channels they're allowed to join.

@persistica/flux-authority

Why Flux?

  • Zero boilerplate — no WebSocket plumbing, no broker config, no custom handshake logic.
  • Auth baked in — the Authority pattern means you write your auth logic; Flux handles the rest.
  • Transport agnostic — Flux moves your messages as raw strings (and, eventually, byte streams); you own the serialization.
  • Channel-based pub/sub — agents publish to named channels and subscribe independently.
  • Portal included — create networks, generate access tokens, and monitor connections in real time.
