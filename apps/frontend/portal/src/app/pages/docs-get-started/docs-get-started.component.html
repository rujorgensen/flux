Get Started

From zero to real-time in about five minutes.

Prerequisites

Flux packages are published on npm and work with Node.js or Bun. You'll need Node.js 20+ or Bun 1.x.

Step 1 — Start the Mesh server

The mesh server is the backbone of your Flux network. Install it in your server project and fire it up:

Install 
bun add @persistica/flux-mesh
server.ts 
{{ meshSnippet }}

That's it. Your mesh server is now listening for connections on port 5100.

Step 2 — Register an Authority

An authority decides who is allowed onto your network and which channels they can join. It's where your authentication logic lives.

Install 
bun add @persistica/flux-authority
authority.ts 
{{ authoritySnippet }}
Where do I get the network ID and authorization key?

Create a network in this Portal, then generate a token from the General Settings page. The network ID is visible in the network selector.

Step 3 — Connect an Agent

Now for the fun part — connecting a client. Agents can run anywhere: in a browser, on a server, or in a background worker.

Install 
bun add @persistica/flux-agent
agent.ts 
{{ agentSnippet }}

You're live! 🎉

At this point you have a mesh server running, an authority validating access, and an agent publishing and subscribing to a channel. That's the full Flux loop.
