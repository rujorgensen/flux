Get Started

From zero to real-time in about five minutes.

Prerequisites

Flux packages work with Node.js 20+ or Bun 1.x.

Package manager: @for (pm of ['bun', 'npm', 'pnpm', 'yarn']; track pm) { }

Step 1 — Start the Mesh server

The mesh server routes connections and messages. Install it and fire it up:

Install
server.ts

Step 2 — Register an Authority

An authority decides who can join your network and which channels they're allowed to subscribe to. This is where your auth logic lives.

Install
authority.ts
Where do I get the network ID and authorization key?

Create a network in this Portal, then generate a token from the General Settings page. The network ID is shown in the network selector.

Step 3 — Connect an Agent

Agents can run anywhere: browser, server, or background worker.

Install
agent.ts

You're live! 🎉

You now have a mesh server running, an authority validating access, and an agent publishing and subscribing to a channel. That's the full Flux loop.
