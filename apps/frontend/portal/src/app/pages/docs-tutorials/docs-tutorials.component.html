Tutorial 1

Build a real-time chat app

~20 min · Beginner · Covers: FluxMesh, FluxAuthority, FluxAgent, channels, pub/sub

Let's build a simple multi-room chat application. Users authenticate with a username and password, join chat rooms (Flux channels), and exchange messages in real time. It's a classic — and it demonstrates everything Flux can do.

What we'll build

  • A mesh server that routes messages between participants
  • An authority that validates user credentials and enforces channel membership
  • An agent for each connected user that sends and receives chat messages

Architecture overview

Alice's browser  ──▶  FluxAgent  ──connect──▶  FluxMesh  ──validate──▶  ChatAuthority
Bob's browser    ──▶  FluxAgent  ──connect──▶  FluxMesh  ──validate──▶  ChatAuthority
                                                   │
                                         joinChannel('general')
                                                   │
                                         publish({ text: 'Hi!' })
                                                   │
                                   ◀── message broadcast to all agents ──▶

What just happened?

Let's recap the flow:

  1. Alice's agent calls connect() with her credentials.
  2. The mesh forwards those credentials to the ChatAuthority.
  3. The authority validates them against the database and returns a JWT identity token.
  4. Alice's agent calls joinChannel('general').
  5. The authority checks whether Alice is a member of general — she is, so she's in.
  6. When Alice publishes a message, the mesh broadcasts it to every agent subscribed to general.

Bob follows the exact same flow from his device. The moment either of them publishes a message, the other sees it instantly. No polling, no long-lived HTTP connections to manage — just clean, real-time pub/sub.

You built a chat app! 🎉

From here you can scale horizontally, add private channels, store message history, or build any other real-time feature on top of this foundation.
