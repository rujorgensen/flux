Tutorial 1

Build a real-time chat app

~20 min · Beginner · Covers: FluxMesh, FluxAuthority, FluxAgent, channels, pub/sub

We'll build a multi-room chat app: users authenticate, join chat rooms (Flux channels), and exchange messages in real time.

What we'll build

  • A mesh server that routes messages between participants
  • An authority that validates user credentials and enforces channel membership
  • An agent for each connected user that sends and receives chat messages

Architecture overview

Alice's browser  ──▶  FluxAgent  ──connect──▶  FluxMesh  ──validate──▶  ChatAuthority
Bob's browser    ──▶  FluxAgent  ──connect──▶  FluxMesh  ──validate──▶  ChatAuthority
                                                   │
                                         joinChannel('general')
                                                   │
                                         publish({{'{'}} text: 'Hi!' {{'}'}})
                                                   │
                                   ◀── message broadcast to all agents ──▶

Step 1 — Start the mesh server

The mesh server routes connections and messages — it doesn't touch your domain logic.

mesh/server.ts

Step 2 — Set up the chat authority

The authority verifies credentials and checks channel membership before letting anyone in.

auth/authority.ts

Step 3 — Connect a chat agent

Each user gets their own FluxAgent. It connects with credentials, joins channels, and starts listening for messages.

client/chat-client.ts

The full flow

  1. Alice connects — her credentials are forwarded to the ChatAuthority, which returns a JWT identity token.
  2. She joins 'general' — the authority checks her channel membership and grants access.
  3. She publishes a message — the mesh broadcasts it to every subscribed agent instantly.
  4. Bob, connected the same way, receives it in real time.
You built a chat app! 🎉

From here you can add private channels, persist message history, or scale horizontally — all on the same foundation.
